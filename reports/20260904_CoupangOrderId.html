1검토 결과

서브 파라미터는 클릭 식별자이며 주문 식별자 불성립
근거 난수 발급 시점 = 링크 클릭 시점. 주문 발생 시점 = 결제 시점. 양자 간 1:1 대응 불성립.
현 시점 판단주문번호 대체 불가
확정 시점검증 완료 후
적용 여부검증 결과에 따라 결정

2목적 미달성

목적부분 취소 시 대상 주문 특정
결과미해결
한계서브 파라미터로 주문 특정 시에도, 1회 클릭 후 다수 상품을 1건으로 결제하면 해당 주문 내 취소 대상 식별 불가
수신 항목쿠팡 수신 항목은 취소 금액에 한정

3발생 가능 문제

상황결과
1회 클릭 후 다수 주문동일 난수에 주문 다건 귀속. 1:N 구조 유지
다수 클릭 후 1회 주문최종 클릭에만 귀속. 이전 난수 무효화
클릭일과 구매일 상이쿠키 만료로 귀속 불가
앱 딥링크 이동앱 세션의 기존 귀속이 우선 적용될 수 있음

4부수 비용

클릭 대비 구매 전환율통상 1~2%
결과미사용 로그 98% 축적
추가 요건회원 단위 집계를 위한 회원 ID 병행 전송

5기대 효과

주문 특정은 불완전. 후보 범위 축소는 가능.

현행회원의 대기 건 전체에서 금액으로 추정
적용 시해당 클릭에서 발생한 건으로 범위 축소
효과오식별 감소

6검증 계획

실구매 · 실취소 필요. 소액 상품으로 진행

확인 항목방법판정 기준

취소 시 값 수신위 주문 전액 취소취소 포스트백에 동일 값 수신 여부

길이 · 문자 제한길이를 달리한 값 전송잘림 · 거부 발생 지점
